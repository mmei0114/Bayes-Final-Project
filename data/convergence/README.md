# 参数与整体似然的补充轨迹

这里保存三类响应的15次MCEM及6次QML/GVA代表性轨迹，共21条。所有数据、种子和所选初始化来自原正式结果；每次只重跑原来选中的一个起点，不重新选择多起点赢家，也不覆盖 `../runs/` 的155次原始拟合。

## 文件

- `{baseline,poisson,nb}_{重复}_{方法}.json`：每轮参数、观测log似然、变化量与最终诊断；MCEM另有Q增量、MCSE、抽样量和接受标记。
- `metadata.json`：预先固定的协议、代码SHA256及初次本地执行环境。混合执行的环境来源另见下面两份清单。
- `local_execution.json`：本地yellow完成的11条记录及哈希，包括6条积分/GVA和5条Poisson MCEM。
- `server_execution.json`：远程base环境、启动前已有记录及服务器补齐的10条二元/负二项MCEM。
- `STATUS.json`：全批次完成数，最终应为21/21；计算结束不表示所有轨迹都通过数值判据。
- `SHA256SUMS`：本目录正式JSON的完整性清单，不含临时检查点。
- `*.checkpoint.json`（计算期间）：原子进度，不上传GitHub；已完成的本地检查点保留于 `../../archive/convergence_20261111/local_checkpoints/`，远程检查点随完整回传保留。

## 固定的诊断口径

每轮用61点自适应Gauss–Hermite计算观测log似然，初始点、原轮数处和终点再用101点核对。连续3轮相对似然变化 `abs(ell_t-ell_prev)/(1+abs(ell_prev)) <= 1e-6`，且MCEM末窗至少有一次接受更新，才记为本次严格口径通过；全部拒绝造成的平直另列。原尺度beta、D、pi的最大缩放变化阈值1e-3仅作辅助，不用于替代似然判断。

MCEM至少运行原记录轮数，必要时最多再延长30轮；达到预算仍未通过则保留未通过，不修改阈值追求通过率。该阈值是本次数值设置，不是老师指定的唯一标准，也不证明全局最优。

补充轨迹是同初始化重跑得到的新记录，原轮数处与保存参数/似然作数值一致性比较。即使吻合，也不将这些点回填进原实验文件；延长后的参数不替换原报告表中的估计或耗时。绘图仅按末端固定效应作一次标签匹配，固定置换应用整条曲线，不按每轮真值重新配对。

在项目根目录执行 `make convergence` 可核验这些输入并重建图表；`make report` 生成更新后的报告。若需要从头重算，应另指定新输出目录，保留已有记录及其协议哈希。
