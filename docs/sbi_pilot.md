# SBI预检协议与记录

2026-11-18，二元模型的阶段A/B预检已完成。下一阶段需要同先验的参数后验参照，再在原固定设计数据上与经典方法比较。方法来源见 [论文记录](sbi_references.md)，后续范围见 [计划](sbi_plan.md)。

## 冻结的模型

沿用三簇随机截距GLMM：每人先抽一个簇U，再抽一个整条轨迹共用的随机截距b；D表示随机截距方差。固定n=300、T=20、t为[-1,1]上等距点，负二项size=5。模拟器已实现三族，本次只训练二元响应；不支持直接改变设计或缺失模式。

训练前冻结的先验为：各簇两个β分量独立N(0,1.5²)；log D独立N(log 0.5,0.7²)，用拒绝抽样限制0.005<D<5；π服从Dirichlet(2,2,2)。按截距递增对整簇β、D、π一起排序，采用此操作诱导的有序先验。β的先验支持为实数，原ML优化边界不充当先验。

连续自由维数11：三个有序截距用首项及相邻正差的log，三个斜率保留实坐标，三个D用区间logit，π用两个中心化stick-breaking坐标。可逆约束参考作者`Constraints.py`；在训练目标坐标中再用训练集均值、标准差标准化。flow拟合标准化后的密度；若比较原参数密度，还需相应变换Jacobian。当前只从flow抽样并反变换，不把未换算密度当作原尺度密度。

## 具体计算技术

遵循Amortized Bayesian Mixture Models的分解：先学习连续全局后验q(θ|Y)，再学习c(Uᵢ|Yᵢ,θ)。网络训练使用先验预测模拟样本，对负对数密度和分类交叉熵作Monte Carlo平均。随机截距通过模拟边缘化；训练不计算难解的观测似然积分，也没有新增EM步骤。

BayesFlow 1.1.6提供六层affine coupling可逆网络，以11维标准正态为基分布，启用ActNorm。每人完整的有序(y,t,mask)向量经共享MLP(128,128,64)，在个体维度取平均，再经MLP(128,128,64)形成数据摘要。二元y编码为±1，t和mask均为可观察设计。摘要不预设为充分统计量。独立分类器使用该人序列的MLP(128,128,32)，拼接标准化θ，经(128,128,3)网络输出softmax；不共享两个网络的权重。隐藏层为ELU。

分类器训练时使用模拟真θ和U；应用时对后验θ抽样，再平均c的类别概率。θ、U和b均不进入后验网络的观察数据输入。条件分类器核验给定同一θ，以原代码的**自适应Gauss–Hermite积分**计算τᵢₖ，61/101点交叉复核；它只作诊断，不参与训练。后验预测检查重新模拟随机截距、簇和响应。

## 数据、训练和停止规则

| 分区 | 完整数据集数量 | 用途 | 根种子 |
|---|---:|---|---:|
| train | 100000 | 离线随机抽批训练、目标标准化 | 20261318 |
| validation | 512 | 选择检查点与预设早停 | 20261418 |
| calibration | 128 | 完成训练后独立覆盖/SBC/预测检查 | 20261518 |
| classifier | 32 | 条件分类器与积分概率核对 | 20261618 |

一份数据集含300人×20次观测。全部分块无损保存，训练每步有放回抽取；重复呈现次数不等于新的独立模拟数。原正式15份比较数据不参与本批训练、验证或校准。数据分块采用SeedSequence([根种子,分块编号])，已保存实际数组和SHA256；每步抽批采用SeedSequence([20261818,步数])。

两网络分别使用Adam，余弦学习率从5×10⁻⁴降到10⁻⁴，全局梯度范数截断10。最多10000步或90分钟，每500步验证并保存完整检查点。NPE验证损失连续8次未改善至少10⁻⁴则停止。NPE检查点沿用这条改善阈值，分类器单独取最低验证交叉熵。GPU批量仅根据128/256/512/1024的吞吐测量选择，校准分区留到训练结束后使用。

先运行二维高斯共轭模型接口检查：θ~N(0,I)，x|θ~N(θ,I/20)，精确后验N(20x/21,I/21)。训练2000步后检验均值、方差、覆盖、flow正逆及保存/重载；预设门槛见`src/sbi_pilot.py`。不通过则停止GLMM训练。训练停止只代表达到预算或验证规则，不等于后验校准合格。

独立诊断固定每份512个后验样本，报告50%/95%覆盖、16箱SBC秩直方图、先验尺度RMSE、收缩、标签Brier/交叉熵及后验预测。128份校准数据的检验能力有限；不以单个阈值宣布SBC证明正确，也不按其结果重选检查点。尚无同先验的合格参数后验MCMC参照，不能据此宣称优于原三种方法。

## 软件与保存

实际服务器为P100 16GB、12逻辑CPU、64GiB内存，继续使用用户指定的base/Python3.11.4。为匹配作者公开代码并适配此次短租，采用BayesFlow1.1.6、TensorFlow2.15.1、TFP0.23，依赖见`requirements-sbi-pilot.txt`。原先计划的BayesFlow2/PyTorch路径暂缓；本地yellow不安装TensorFlow。数据生成先于训练依赖安装，使用服务器原有NumPy2.0.0；数组已经完整保存，训练阶段使用NumPy1.26.4。两阶段环境和执行源码分别归档。

下载GPU依赖慢时已告知用户，查看官方`pip_source`后选用清华源；大包采用有界并行HTTP Range下载，按PyPI公布的大小及SHA256逐个验证后安装。安装失败/中止日志一并保留，不以最终成功掩盖过程。

完整数据、冻结执行源码、日志、环境、网络/优化器/步数检查点和后验样本保存在本地`cloud/received/runs/sbi_*`。开始训练前本地保留了上传快照。训练批次由步数确定，程序提供断点续训入口，本轮一次运行完成。最终备份清单见 [逐文件校验记录](../qa/sbi_pilot/cloud_SHA256SUMS)。

## 实测结果

| 检查 | 结果 |
|---|---|
| 高斯解析后验 | 95%区间覆盖96%，均值RMSE为精确后验标准差的0.093倍，中位方差比1.004，重载样本最大差0 |
| 二元训练 | P100批量1024，10000步约34.6分钟。共用100000份预生成数据，有放回抽取累计呈现1024万次。按验证损失选中NPE第9500步、分类器第10000步 |
| 128份独立校准数据 | 12个参数分量的95%区间覆盖91.4%–97.7%，50%区间覆盖39.8%–60.2%。每份数据抽取512个后验样本 |
| 随机截距方差 | D₂的50%覆盖为39.8%，95%覆盖为91.4%。三个D的平均后验方差相对先验的收缩为−6.6%、13.0%、9.4% |
| 给定真参数的分类概率 | 32份数据，GH概率RMSE为0.0239，最大概率标签一致率为97.9% |
| 对参数后验积分后的分类 | 128份数据，原始有序标签准确率67.0%，Brier分数0.434，交叉熵0.718 |

二元实现通过了模拟器、参数变换和解析后验检查。方差成分的收缩有限，D₂的区间覆盖偏低。现有诊断无法区分模型自身的信息有限与神经后验的近似误差。下一步先在同一个二元模型、同一先验下做合格MCMC参照，再决定是否扩大训练量。给定真参数时的分类一致率衡量条件分类器的近似误差，两种分类结果对应不同诊断。
