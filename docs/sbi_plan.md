# SBI扩展计划：BayesFlow混合模型推断

2026-11-18已完成论文调研和二元模型的阶段A/B预检。冻结先验、实现、分区、停止规则和诊断结果见 [预检记录](sbi_pilot.md)，来源与阅读范围见 [文献核对](sbi_references.md)。下一阶段优先建立同先验的二元后验参照，再据此确定正式训练规模。

## 1. 建议与范围

建议增加一个独立的现代方法：**BayesFlow神经后验估计（NPE）＋条件簇分类器**，主要依据Kucharský–Bürkner《Amortized Bayesian Mixture Models》§2.3–2.4、§3.1–3.2，结合现有随机截距GLMM。不是另造“flow-EM”，也不把分类网络单独称作完整贝叶斯推断。

首轮固定K=3、n=300、T=20、时间设计和负二项size=5。先做二元基准，通过核验后再分别训练Poisson、负二项模型；三类响应各自训练，不假定一个网络自动支持所有响应族。用原三类响应各5份数据作独立比较集；它们及其真值不得参与训练、调参和早停。新增固定设计测试重复可在预算明确后冻结。

本次不承诺覆盖K=2/4、n/T改变或不规则时点。原14场景结果继续保留，新方法的比较范围单独写明；超出训练设计不能直接宣称泛化。

## 2. 推断目标与论文方法

令θ=(β,D,π)，全局连续自由维数为6+3+2=11。以一整条个体序列Yᵢ为一个混合观测单位，随机截距bᵢ在模拟中生成，作为干扰变量边缘化；连续flow不直接输出离散Uᵢ。

论文的独立混合分解在本题成为

\[
p(\theta,U\mid Y)=p(\theta\mid Y)\prod_i p(U_i\mid Y_i,\theta).
\]

- 后验网络：学习qφ(θ｜h(Y))，训练损失为先验预测分布下的E[−log qφ(θ｜h(Y))]。
- 分类网络：学习cψ(Uᵢ｜Yᵢ,θ)，用模拟器生成的Uᵢ计算交叉熵。训练时条件是模拟真θ，应用时换成后验θ样本；不能一直代入一个点估计。
- 应用时先抽θ⁽ˢ⁾，再计算cψ(k｜Yᵢ,θ⁽ˢ⁾)，平均得到簇归属概率，取最大概率作为比较用标签。训练标签来自模拟器，不使用待聚类数据的真实标签。

这对应论文式(11)、(14)–(17)及图3。可按论文允许的分模块训练实现，首轮不共享两任务的局部编码器权重，避免接口迁移时额外引入联合损失权重。

## 3. 必须补齐的模型与实现事项

1. **先验。** 现有MCEM/GVA/QML是参数点估计，原优化边界不是先验。SBI新增的适当可积先验须与后验参照完全一致。本批已在训练前冻结：β独立N(0,1.5²)，D为截断至(0.005,5)的LogNormal(log 0.5,0.7²)，π为Dirichlet(2,2,2)，随后按截距排序整簇参数。先验预测检查包含计数尾部、全0/全1轨迹及极小簇；没有根据测试拟合结果调窄先验，具体检查见`qa/sbi_pilot/`。
2. **标签与约束。** 采用β₀₁<β₀₂<β₀₃作为标签约定；生成时对完整簇参数和标签作同一置换，使用排序后诱导先验，不用真值逐轮配对。π用K−1个实坐标；方差和有序系数用标准可逆约束变换。依据作者实际`Constraints.py`及Stan变换文档核对双向一致性和所需Jacobian，不能靠截断网络输出修正非法样本。排序也不消除真实的弱识别性。
3. **模拟器。** 现有`legacy_model.generate`固定了β、π与共同方差，不能直接用于全局先验预测训练。另加接收任意θ的接口，复用同一生成机制，核对三类响应、簇特异D和时点/缺失掩码；原155次拟合输入不覆盖。真实θ、U、b只作训练目标/诊断信息，不进入观察数据编码器。
4. **数据表示。** 首轮固定T=20，每人完整的有序(y,t,mask)向量经共享MLP编码，个体集合经DeepSet汇总；分类器读取该人的完整序列与θ。保留个体内的时间对应及相关信息，只在个体维度要求置换不变，不能将nT条测量打散成独立样本。摘要压缩可能丢失信息，不预设其充分性，需由校准和参照检查。变T时需另行核对层级/序列编码，不直接复用本轮网络。
5. **网络与软件。** 使用BayesFlow提供的条件coupling flow，分类端为标准MLP＋softmax。实际预检使用Python3.11/P100上与作者代码对应的BayesFlow1.1.6/TensorFlow2.15.1及`InvertibleNetwork` affine coupling接口。解析解和保存重载通过，独立校准结果见预检说明。此前调研的BayesFlow2/PyTorch路径留待后续评估。

## 4. 比较与正确性检查

| 层面 | 实际做法 |
|---|---|
| 聚类与点估计 | 与MCEM/GVA/QML用同一独立数据，报告ARI、匹配错分率、β/D/π的RMSE；SBI点摘要的选择在测试前固定 |
| 分类器近似 | 给定相同θ，以现有61点GH（101点复核）的τᵢₖ=πₖAᵢₖ/ΣₕπₕAᵢₕ核对分类概率，另报Brier/校准；积分仅用于核验，不参与网络训练 |
| 参数后验 | 新增同模型、同先验的全贝叶斯参照；优先Stan/NUTS，对U精确求和并对连续随机效应采样，必要时采用经推导核对的标准非中心化参数化。至少先检查每族1份代表数据 |
| MCMC资格 | 检查多链rank R-hat、bulk/tail ESS、divergence及模式敏感性；未通过者不能叫后验真值。现有固定θ条件MH链不是这个参照 |
| SBI校准 | 独立先验预测测试集上的SBC、区间覆盖、参数恢复/收缩、后验预测检查；与合格MCMC比较边缘/联合分布，可用C2ST。SBC近似均匀和训练loss下降均不是充分正确性证明 |
| 计算成本 | 分开记录模拟、训练、预处理、后验抽样和分类耗时；同机重测代表性的经典方法，注明GPU/CPU资源。报告一次性总成本和重复使用的摊销成本，不能只拿推断秒数比含多起点的旧服务器总耗时 |

神经网络的校验损失和独立校准是新方法诊断；不能套用原MCEM“小Q增量”或“似然3轮平稳”来判定神经后验正确。训练随机种子与数据重复分开记录，后续建议3个训练种子，不把它们当作新增独立测试数据。

## 5. 分阶段执行与预算

- **阶段A：模型与代码核验（完成）。** 完成先验、参数变换、三族模拟器、P100矩阵计算和高斯解析后验核验，验证了网络保存与重载。
- **阶段B：二元短试跑（完成）。** 使用10⁵份独立模拟训练数据，每份300×20个测量。10000步训练约34.6分钟，完成128份独立后验校准与32份条件分类器积分核验。部分方差分量的区间覆盖和收缩较弱。
- **阶段C：冻结正式设置。** 根据试跑给出10⁶级及必要的更高模拟预算、训练步数和GPU小时估计，固定验证集、早停和最大预算。论文§3.3的示例用了100×2000×128=25,600,000个在线生成数据集，不能将我们的较小预算称为完整复现，更不能预先保证数小时达标。
- **阶段D：扩展与评估。** 二元实现与诊断合格后扩展两种计数响应；各族独立SBC建议500份先验预测数据、每份约1000个后验样本，具体预注册设置在正式训练前固定。另行完成固定设计的原15份数据比较及同先验后验参照。校准失败时报告不足，不按测试效果随意修改规则。
- **阶段E：入报告。** 只写已运行的方法和结果，增加简短方法小节、比较表、校准/后验图与成本说明；GVA保留。正文仍服从作业15页（图和参考文献不计）的限制。

## 6. 建议租用的服务器

下表是制定预检前的租用建议。实际P100 16GB已经完成二元试跑，批量1024的双网络训练峰值分配约1.7GB。正式工作还需根据同先验参照和计数模型预检的实测定预算。

| 资源 | 建议 |
|---|---|
| GPU | 1张NVIDIA CUDA卡，24GB显存，例如RTX 4090；单卡起步，不先租多卡/A100 |
| CPU | 12–16个可用逻辑核心，承担模拟与MCMC/积分核验 |
| 内存 | 推荐64GB；32GB可做缩小批次的预检，但需实测 |
| 磁盘 | 至少200GB可用SSD；采用在线生成或分块读取，不把百万份数据全驻内存 |
| 软件 | Linux、Python 3.12、可用CUDA版PyTorch；远程继续使用用户指定base的前提是该base满足依赖。若新服务器环境不符，先报告，不自行切换Conda环境 |
| 租用方式 | 先短租约4小时作接入与阶段A/B，按实际吞吐/校准和预算再确定续租；不承诺4小时完成三类响应的全部实验 |

GPU主要服务神经训练，CPU仍重要。24GB显存与200GB SSD用于留余量，不是已经测得的峰值；选择具体机型时还要核对驱动及镜像兼容性。

## 7. 文件与保存

将来在同一项目根目录的`src/`、`data/`、`results/`、`figures/`、`qa/`按用途添加SBI文件，不建立revision目录。训练前本地保存源码、先验/设计/依赖/种子配置；运行中回传完整checkpoint（网络、优化器与随机状态）、日志和固定验证输出；结束回传权重、训练历史、后验样本、校准输入及SHA256。可重生成的大型训练流保存确定的生成协议/状态，若实际落盘则同步保留分块数据及清单，明确区分已归档数据与可重生成流。
